Instrucciones de uso

Preparación

  1. Instala R ≥ 4.2 (recomendado: 4.5.x)
  2. Instala RStudio ≥ 2023.x (última versión estable)
  3. Instala Rtools compatible con tu versión de R
    Rtools45 para R 4.5.x  ·  Rtools44 para R 4.4.x  ·  solo Windows
  4. Descarga los datos desde la pestaña Datos
  5. Organiza la carpeta de trabajo:
    Data/OBS/   Data/SIG/
    Data/PISCO/   Data/CHIRPS/

Dentro del tutorial

  • Los paquetes se instalan automáticamente
  • Ejecuta el código bloque por bloque en RStudio
  • Usa los botones de navegación en la parte superior para ir entre partes
  • Descarga el código fuente con el botón Descargar .Rmd
